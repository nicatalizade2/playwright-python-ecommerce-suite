## 🛠️ Tech Stack
*   **Language:** Python
*   **Testing Tool:** Playwright (Pytest-Playwright)
*   **Database:** PostgreSQL (Containerized)
*   **API Layer:** FastAPI Service
*   **Environment:** Docker & Docker Compose
*   **CI/CD:** GitHub Actions
